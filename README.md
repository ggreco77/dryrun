# GRAWITA DRY RUN

**An experimental web-based tool for gravitational-wave electromagnetic follow-up planning.**

GRAWITA DRY RUN is a prototype for testing interactive sky localization, astronomical survey coverage, and observational planning for multi-messenger astronomy.

### Features

- Visualization of gravitational-wave sky maps and credible regions.
- MOC-based intersections with astronomical survey footprints.
- Probability-guided and contiguous field-of-view planning.
- Interactive coverage analysis and observational paths.
- Integration of telescope fields and GLADE+ galaxy data.

### Demo

The default event, **MS261006h**, is a simulated gravitational-wave event (MDC) used exclusively for testing and demonstration.

**This software is experimental and is not intended for operational observing decisions without independent scientific validation.**

### Technology

JavaScript · Aladin Lite · MOCWasm · HEALPix

### Project background

GRAWITA DRY RUN is an experimental reworking of **GWsky**, serving as a testbed for multi-messenger observational planning and exploring **AI agent-assisted software development and testing**.
